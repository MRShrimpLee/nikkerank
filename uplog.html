版本与改动记录

1.1.0

  • 新增可选项「去除异格角色」：妮姬同名换皮版本共 47 名，勾选后只保留 158 名本体。
  • 换皮识别规则为「本体名：后缀」（全角冒号），另有「零 (暂称)」这类括号写法单独登记； 每名换皮都记录本体名与本体 id，安妮：奇迹仙女 的本体是 N102。
  • 与「去除联动角色」可叠加，两者交集 2 名（明日香：WILLE、零 (暂称)），按并集扣除不重复计算。
  • 测试 45 → 53 项，新增异格标记一致性、本体可追溯性、重名检查等。

1.0.0

  • 首个版本：以「明日方舟干员喜好排序」为模板做的妮姬版，排序引擎（js/engine.js）完全复用。
  • 收录 205 名妮姬：中文名、稀有度、职业、企业、爆裂阶段、武器、属性、部队、CV、实装日期，以及 512 级别以内的角色卡片图。
  • 筛选树支持 6 个维度：稀有度 / 职业 / 企业 / 爆裂阶段 / 武器 / 属性，可任意组合，另有「去除联动角色」开关（24 名 / 9 个 IP）。
  • 结果页提供前 N 名排行、完整结果表（可一键复制）与偏好分析（按部队/企业/职业/武器/属性统计）。
  • 键盘快捷键、触屏常显角色名、设置记忆（localStorage）、题量预估。
  • 数据由 tools/gen_data.py 从 GameKee 妮姬百科抓取生成，tools/fetch_avatars.py 增量下载头像。
  • 测试 tools/test_engine.js 覆盖排序正确性、题量上下界、回退/剔除/随机、数据集完整性等。

如何更新角色数据

python tools/gen_data.py        # 重新生成 js/data.js（增量缓存，只抓新角色）
python tools/fetch_avatars.py   # 增量下载缺失的头像
