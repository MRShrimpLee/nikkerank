这是什么

这是一个「二择」式的妮姬喜好排序器：每次只给你两位妮姬，你只要点击更喜欢的那一位， 若干轮之后就能得到你的前 N 名排行。相比直接给两百多位妮姬打分，这种两两比较的方式 更轻松，也更接近你真实的直觉。

本站与 明日方舟干员喜好排序 是同一个系列，排序引擎完全相同，都源自 uzkk/favorite（MIT 协议，作者 Shigma）， 按妮姬的数据结构重做了筛选维度与卡片展示。整站是零构建静态站点：没有框架、没有构建步骤， 双击 index.html 就能运行，也可以直接托管在 GitHub Pages 上。

关于算法

排序原理是 Pairwise Comparison（两两比较）。 每答一题，胜者保留在候选池中，败者被挂到胜者名下，形成一棵二叉树； 当候选池只剩一位时，它就是第 1 名，然后沿着树继续向下钻取，依次确定第 2、3…… 名。 

总轮数 ≈ (N − 1) + (排名数 − 1) × log₂N

例如从 205 名妮姬中排出前 10 名约需 310 轮，前 1 名约需 204 轮；而两两全比需要 205 × 204 ÷ 2 = 20910 轮。设置页会直接给出当前配置的预计轮数。 根据选择的先后顺序，结果可能会略有不同；这也是「本命测试」的乐趣所在。

偏好分析的算法

从你的前 m 名出发，对每个标签 k： 

你的占比  S_k = Σ（前 m 名中带标签 k 的角色权重） / Σ（全部权重），权重 w_i = 1 / (1 + i)
全体占比  B_k = 参测角色中带标签 k 的人数 / 参测人数
参考值    w_k = S_k − B_k

参考值大于 0 表示你比随机情况更偏爱这个标签；≥ 0.2 的标签会作为「XX 控」显示出来。 排名少于 7 名时不做统计。这里的标签取自每位妮姬的 所属部队、企业、职业、武器与属性—— 所以「XX 控」可能是「宙斯盾部队控」「发射器控」「朝圣者控」这类。

数据来源

  • 角色数据与头像：GameKee 妮姬百科 · 角色图鉴 （每个角色页的结构化资料：稀有度 / 职业 / 企业 / 爆裂阶段 / 武器 / 属性 / 部队 / CV / 实装日期）。
  • 数据规整（都记录在 tools/report.json 里）：
    • 4 名「超标准」角色的企业名带后缀（如「米西利斯（超标准）」），已统一为企业本体并保留 overflow 标记；
    • 1 名角色的属性百科写作「雷电」，已统一为「电击」（游戏内只有 5 种属性）；
    • 3 名角色（马斯特、爱德、爱丽丝：仙境兔女郎）的职业百科写作「支援型」， 而百科自身的筛选器只有 火力型/防御型/辅助型 三类，已统一为「辅助型」。
  • 更新方式：在项目根目录执行 python tools/gen_data.py 与 python tools/fetch_avatars.py，会增量抓取新角色与缺失头像。

使用提示

  • 把鼠标移到卡片上可以看到角色名、所属部队、职业 / 稀有度 / 阶段 / 属性。
  • 点错了可以按「等下，选错了……」或键盘 Backspace 退回上一题。
  • 键盘快捷键：1 / ← 选左边，2 / → 选右边，R 本题随机。
  • 对某位妮姬不感兴趣，可以用「不再出现左边的角色」把她从后续题目中剔除。
  • 设置会记在浏览器本地（localStorage），下次打开会恢复上次的选择。
